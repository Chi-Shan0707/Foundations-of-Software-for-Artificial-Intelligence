## 课程讲义覆盖

- 以 Python 实现最小神经网络，建立"输入 → 隐藏层 → 输出"的整体计算视角。
- 串联激活函数（ReLU / Sigmoid）、损失函数（MSE）与梯度下降更新。
- 课堂样例将 `factorial(x)` 变换为 `log(factorial(x))` 以缓解数值爆炸。
- 强调"训练集拟合 + 未见样本测试"是评估模型而非只看训练误差。

---

## 课程核心

1. **数据表示先行** — 阶乘增长极快，先做对数映射可显著稳定训练。
2. **前向传播** — 线性变换 + 非线性激活决定模型表达能力。
3. **反向传播** — 链式法则把输出误差拆回每层参数的梯度。
4. **学习率权衡** — 步长过大震荡、过小收敛慢；需结合损失曲线调参。

---

## 知识脉络

```
输入 x → 线性层 W1,b1 → 激活函数 → 输出层 W2,b2 → Loss
                                                      ↓
                                              梯度下降更新参数
```

## 代码与实践

课堂代码（`facnn.py` / `factorial_neuralnetwork.py`）展示了手写训练环节：

```python
for i in range(self.hidden_size):
    z[i] = self.W1[i] * x + self.b1[i]
    h.append(max(0, z[i]))  # ReLU
...
error = y - target
dL_dy = error
dL_dW2 = [dL_dy * h[i] for i in range(self.hidden_size)]
self.W2[i] -= lr * dL_dW2[i]
```

- 训练目标是拟合 `log(factorial(x))`，再通过 `exp` 映射回原始量级。
- 实践结论：同一网络结构下，激活函数与学习率组合直接决定收敛速度。

## 速记

- 前向：`x → z = Wx+b → h = act(z) → y`
- 反向：先算 `dL/dy`，再链式回传到每个参数。
- 对数变换常用于抑制数值尺度问题。
- 训练损失低 ≠ 泛化好，必须看测试误差。
