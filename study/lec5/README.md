## 1. 无监督学习基础

### 1.1 监督学习 vs 无监督学习

| | 监督学习（Supervised） | 无监督学习（Unsupervised） |
|--|----------------------|--------------------------|
| **数据** | 有样本 + 标签（如：红色汽车、蓝色飞机） | 仅有样本，无标签 |
| **目标** | 学习从输入到标签的映射 | 发现数据内在结构或模式 |
| **典型任务** | 分类、回归 | 聚类、降维、生成 |
| **标注成本** | 高（需人工逐条标注） | 低（无需标注） |

### 1.2 无监督学习的两大思路

```
┌─────────────────────────────────────────────────────────────────────┐
│                     无监督学习的两大方向                              │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  ┌─────────────────────────┐    ┌─────────────────────────┐        │
│  │   化繁为简（降维）        │    │  无中生有（生成模型）     │        │
│  │                         │    │                         │        │
│  │  - 聚类（K-means等）     │    │  - GMM 概率建模         │        │
│  │  - 降维（PCA）          │    │  - 大语言模型（LLM）     │        │
│  │  - 特征提取             │    │  - 图像生成（GAN等）     │        │
│  │                         │    │                         │        │
│  │  目标：从高维中提炼关键   │    │  目标：学习数据分布，    │        │
│  │  信息，实现压缩与分析    │    │  生成新的合成数据        │        │
│  └─────────────────────────┘    └─────────────────────────┘        │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 1.3 核心问题：相似度度量

聚类的关键在于定义数据之间的**相似度**。距离度量（Metric）必须满足以下三个数学特性：

| 特性 | 数学表达 | 直觉含义 |
|------|---------|---------|
| **非负性** | $d(x_i, x_j) \geq 0$ | 距离不能为负 |
| **对称性** | $d(x_i, x_j) = d(x_j, x_i)$ | A 到 B 的距离等于 B 到 A 的距离 |
| **三角不等式** | $d(x_i, x_j) \leq d(x_i, x_k) + d(x_k, x_j)$ | 绕路不会更近 |

常见的距离度量：

| 距离类型 | 公式 | 直觉 |
|---------|------|------|
| **欧式距离（Euclidean）** | $d = \sqrt{\sum_{i}(x_i - y_i)^2}$ | 两点之间的直线距离 |
| **曼哈顿距离（Manhattan）** | $d = \sum_{i} \lvert x_i - y_i \rvert$ | 沿坐标轴的"城市街区"距离 |
| **余弦距离** | $d = 1 - \frac{x \cdot y}{\|x\| \|y\|}$ | 方向差异，常用于文本 |

> **学习要点**：距离的选择是一个**超参数**，直接影响聚类效果。不同的距离度量适用于不同的数据类型——图像数据常用欧式距离，文本数据常用余弦距离。选择合适的距离度量往往是区分算法效果好坏的关键。

## 2. K-means 聚类算法

### 2.1 核心思想

K-means 是最经典的聚类算法之一。其目标是将 $N$ 个数据点划分为 $K$ 个簇（Cluster），使得：

- **簇内相似度高**（Intra-cluster similarity）：同一簇内的点尽量紧密团结。
- **簇间相似度低**（Inter-cluster similarity）：不同簇之间的点尽量远离。

### 2.2 算法流程

K-means 本质上是一种**交替优化（Alternating Optimization）**算法：

```
┌─────────────────────────────────────────────────────────────────────┐
│                     K-means 算法流程                                 │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  输入：数据集 D = {x₁, x₂, ..., xₙ}, 簇数 K, 距离度量 d(·,·)       │
│                                                                     │
│  Step 1: 随机初始化 K 个簇中心 μ₁, μ₂, ..., μₖ                      │
│              ↓                                                      │
│  Step 2: 分配（Assignment）                                         │
│          对每个数据点 xᵢ，计算它到所有簇中心的距离，                    │
│          将 xᵢ 分配到最近的簇：                                      │
│          cᵢ = argmin_k d(xᵢ, μₖ)                                    │
│              ↓                                                      │
│  Step 3: 更新（Update）                                             │
│          重新计算每个簇的中心（取簇内所有点的均值）：                    │
│          μₖ = (1/|Cₖ|) Σ xᵢ,  xᵢ ∈ Cₖ                              │
│              ↓                                                      │
│  Step 4: 重复 Step 2-3，直到簇中心不再变化（收敛）                    │
│                                                                     │
│  输出：K 个簇的划分 {C₁, C₂, ..., Cₖ} 和对应的簇中心 {μ₁, ..., μₖ}   │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 2.3 手动计算示例

假设有 6 个二维数据点，$K=2$，使用欧式距离：

| 点 | 坐标 |
|----|------|
| $P_1$ | (1, 1) |
| $P_2$ | (2, 1) |
| $P_3$ | (1, 2) |
| $P_4$ | (8, 8) |
| $P_5$ | (9, 8) |
| $P_6$ | (8, 9) |

**迭代过程**：

1. **初始化**：随机选 $P_1(1,1)$ 和 $P_4(8,8)$ 作为初始中心。
2. **第 1 次分配**：计算每个点到两个中心的距离，$P_1, P_2, P_3$ 离 $P_1$ 近，$P_4, P_5, P_6$ 离 $P_4$ 近。
3. **第 1 次更新**：
   - 簇 1 新中心 = $((1+2+1)/3, (1+1+2)/3) = (1.33, 1.33)$
   - 簇 2 新中心 = $((8+9+8)/3, (8+8+9)/3) = (8.33, 8.33)$
4. **第 2 次分配**：重新计算距离，分配不变。
5. **第 2 次更新**：簇中心几乎不变 → **收敛**。

### 2.4 优化目标

K-means 的优化目标可以写为：

$$
\min \sum_{k=1}^{K} \sum_{x_i \in C_k} \| x_i - \mu_k \|^2
$$

即最小化所有簇内点到其簇中心的**平方距离之和**（Within-Cluster Sum of Squares, WCSS）。

### 2.5 优缺点

| 优点 | 缺点 |
|------|------|
| 算法简单，易于理解和实现 | 必须预先指定簇数 $K$ |
| 在低维数据上收敛快 | 对不规则形状（如环形、月牙形）聚类效果差 |
| 可解释性强 | 计算复杂度高：每次迭代需遍历所有 $N \times K$ 个距离 |
| | 对初始化敏感，可能陷入局部最优 |

### 2.6 应用场景

- **图像分割**：将每个像素视为一个三维数据点（R, G, B），用 K-means 进行颜色聚类。
- **文本聚类**：将文章用词向量表示后，按主题进行聚类。
- **客户分群**：根据消费行为特征对用户进行分群。

## 3. DBSCAN 密度聚类算法

### 3.1 K-means 的局限

K-means 基于距离划分，对以下数据形态效果很差：

```
  K-means 的困境：

        · ·           · ·
       ·   ·    vs    ·   ·
      ·     ·         ······      ← 环形数据
       ·   ·          ·   ·
        · ·            · ·

  K-means 会用直线切割，而 DBSCAN 可以识别环形结构
```

### 3.2 核心思想

DBSCAN（Density-Based Spatial Clustering of Applications with Noise）基于**密度**进行聚类，像一个"病毒传染"过程：

- 密集区域中的点互相"感染"，形成同一个簇。
- 稀疏区域中的点无法被感染，标记为**噪声（Noise）**。

### 3.3 关键概念与超参数

| 概念 | 符号 | 含义 |
|------|------|------|
| **Epsilon（ε）** | 半径 | 定义一个点的"邻域"范围 |
| **MinPts** | 最小点数 | 一个点成为"核心点"所需的邻域内最少样本数 |

三类点的定义：

```
┌─────────────────────────────────────────────────────────────────────┐
│                    DBSCAN 中的三类点                                 │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  核心点（Core Point）                                                │
│  ┌─────────────────────┐                                            │
│  │  ε 邻域内 ≥ MinPts  │  → 可以"感染"其他点，是簇的生长点           │
│  └─────────────────────┘                                            │
│                                                                     │
│  边界点（Border Point）                                              │
│  ┌─────────────────────┐                                            │
│  │  ε 邻域内 < MinPts  │                                            │
│  │  但在某个核心点邻域内 │  → 被核心点"感染"，属于该簇               │
│  └─────────────────────┘                                            │
│                                                                     │
│  噪声点（Noise Point）                                               │
│  ┌─────────────────────┐                                            │
│  │  不在任何核心点邻域内 │  → 无法被感染，独立成一类（或丢弃）        │
│  └─────────────────────┘                                            │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 3.4 算法流程

```
1. 随机选择一个未标记的样本 x
2. 计算 x 的 ε 邻域内的样本数量
3. 如果数量 ≥ MinPts → x 是核心点
     将 ε 邻域内的所有点标记为同一簇
     对邻域内的每个点重复步骤 2-3（递归扩展）
4. 如果数量 < MinPts → x 暂时标记为噪声
5. 重复步骤 1-4，直到所有样本都被处理
```

### 3.5 K-means vs DBSCAN 对比

| | K-means | DBSCAN |
|--|---------|--------|
| **聚类依据** | 距离（到簇中心） | 密度（邻域内点数） |
| **簇的数量** | 需要预设 $K$ | 自动确定 |
| **簇的形状** | 倾向球形 | 任意形状 |
| **噪声处理** | 无法识别噪声点 | 可以识别并标记噪声 |
| **超参数** | $K$、距离度量 | ε、MinPts |
| **计算复杂度** | $O(NKd)$ 每次迭代 | $O(N \log N)$（使用空间索引时） |

> **超参数选择提示**：ε 过小 → 每个点都是单独的簇；ε 过大 → 所有点被归为同一个簇。MinPts 通常取 $\geq \text{数据维度} + 1$，常用初始值为 $\text{MinPts} = 2 \times \text{维度}$。

## 4. 主成分分析（PCA）

### 4.1 降维的动机

高维数据存在**维度灾难**问题：
- 计算开销巨大（如 10000 维数据的协方差矩阵为 $10000 \times 10000$）。
- 可视化困难（人类只能直观理解 1-3 维数据）。
- 许多维度包含冗余信息。

**降维的目标**：找到一个低维空间，将数据投影到该空间中，使得：
1. **最近重构性**：投影后的数据点到低维空间的距离足够小（信息损失小）。
2. **最大可分性**：投影后的数据点在新空间中尽可能分散开。

> **关键定理**：这两个目标在数学上是**等价的**——最大化投影方差 = 最小化重构误差。下面会分别推导并证明这一点。

### 4.2 直觉理解

```
  二维数据投影到一维：

        ·  ·                                        ·  ·
       · ·  ·    投影到蓝色方向 → 点仍然分散 ✓       ╲
      ·   · ·       → 信息保留多                     ╲·  ·  ·
        · ·     投影到绿色方向 → 点挤在一起 ✗          ╲· ·  ·
       ·  ·        → 信息损失严重                    · ·
        ·                                            ·
    蓝色方向（方差大）好          绿色方向（方差小）差

    → 我们要找的就是"方差最大"的投影方向
```

### 4.3 数学推导：最大可分性视角

**步骤 1：数据预处理（均值归一化）**

$$
\bar{x} = \frac{1}{N} \sum_{i=1}^{N} x_i, \quad x_i' = x_i - \bar{x}
$$

将所有数据中心化，使得均值为 0。

**步骤 2：投影的方差最大化**

设 $w_1$ 是一个**单位向量**（$\|w_1\| = 1$），数据点 $x_i$ 在 $w_1$ 方向上的投影为 $w_1^T x_i$。投影后数据的方差为：

$$
\text{Var}(w_1) = \frac{1}{N} \sum_{i=1}^{N} (w_1^T x_i)^2 = w_1^T \left( \frac{1}{N} \sum_{i=1}^{N} x_i x_i^T \right) w_1 = w_1^T S w_1
$$

其中 $S = \frac{1}{N} \sum_{i=1}^{N} x_i x_i^T$ 是数据的**协方差矩阵（Covariance Matrix）**。

**步骤 3：优化问题**

$$
\max_{w_1} \; w_1^T S w_1 \quad \text{s.t.} \quad w_1^T w_1 = 1
$$

使用**拉格朗日乘数法**，构造：

$$
\mathcal{L}(w_1, \lambda) = w_1^T S w_1 - \lambda(w_1^T w_1 - 1)
$$

对 $w_1$ 求导并令其为零：

$$
Sw_1 = \lambda w_1
$$

这正是**特征值问题**！$\lambda$ 是协方差矩阵 $S$ 的特征值，$w_1$ 是对应的特征向量。

**结论**：选择 $S$ 的**最大特征值**对应的特征向量 $w_1$ 作为第一主成分方向，投影后的方差最大。

### 4.4 数学推导：最近重构性视角

将数据 $x_i$ 投影到 $w_1$ 方向后，重构值为 $\hat{x}_i = w_1 w_1^T x_i$。重构误差为：

$$
J = \sum_{i=1}^{N} \| x_i - \hat{x}_i \|^2 = \sum_{i=1}^{N} \| x_i - w_1 w_1^T x_i \|^2
$$

展开并化简（利用 $w_1^T w_1 = 1$）：

$$
J = \text{tr}(S) - w_1^T S w_1
$$

其中 $\text{tr}(S)$ 是协方差矩阵的迹，是一个常数。因此：

$$
\min J \iff \max \; w_1^T S w_1
$$

**两个视角完全等价！**

### 4.5 PCA 的完整算法

```
┌─────────────────────────────────────────────────────────────────────┐
│                     PCA 算法步骤                                     │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  输入：数据矩阵 X ∈ R^(N×d), 目标维度 k                              │
│                                                                     │
│  Step 1: 均值归一化                                                  │
│          x̄ = mean(X),  X' = X - x̄                                  │
│                                                                     │
│  Step 2: 计算协方差矩阵                                              │
│          S = (1/N) X'^T X'   ∈ R^(d×d)                              │
│                                                                     │
│  Step 3: 特征值分解                                                  │
│          S wᵢ = λᵢ wᵢ,  i = 1, 2, ..., d                           │
│          按特征值从大到小排列：λ₁ ≥ λ₂ ≥ ... ≥ λ_d                   │
│                                                                     │
│  Step 4: 选择前 k 个主成分                                           │
│          W = [w₁, w₂, ..., wₖ]   ∈ R^(d×k)                          │
│                                                                     │
│  Step 5: 投影到低维空间                                              │
│          Z = X' W   ∈ R^(N×k)                                       │
│                                                                     │
│  输出：低维表示 Z ∈ R^(N×k)                                          │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

**各主成分的解释**：

| 主成分 | 对应特征值 | 方向 | 方差贡献 |
|--------|----------|------|---------|
| 第 1 主成分 $w_1$ | $\lambda_1$（最大） | 数据散布最广的方向 | $\lambda_1 / \sum \lambda_i$ |
| 第 2 主成分 $w_2$ | $\lambda_2$（次大） | 与 $w_1$ 正交的次优方向 | $\lambda_2 / \sum \lambda_i$ |
| 第 $k$ 主成分 $w_k$ | $\lambda_k$ | 与前 $k-1$ 个方向正交 | $\lambda_k / \sum \lambda_i$ |

### 4.6 PCA 的去相关性

协方差矩阵 $S$ 的非对角元素表示不同特征之间的相关性。经过 PCA 变换后，投影数据 $Z$ 的协方差矩阵为：

$$
\frac{1}{N} Z^T Z = W^T S W = \text{diag}(\lambda_1, \lambda_2, \dots, \lambda_k)
$$

这是一个**对角矩阵**，意味着各主成分之间**互不相关**。PCA 同时实现了降维和去相关。

## 5. PCA 应用：Eigenface 人脸识别

### 5.1 问题背景

人脸识别的核心挑战：一张 $98 \times 116$ 像素的灰度图像就是一个 11368 维的向量。直接在高维空间进行比对计算量巨大。

**直觉**：人识别他人时，不会盯着每一个像素看，而是关注几个关键特征（眼睛、鼻子、轮廓等）。PCA 可以自动找到这些"关键特征"。

### 5.2 Eigenface 方法

```
┌─────────────────────────────────────────────────────────────────────┐
│                     Eigenface 人脸识别流程                           │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  训练阶段：                                                          │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐      │
│  │ M 张人脸  │───→│ 均值归一化 │───→│ 计算协方差 │───→│ 特征值   │      │
│  │ 图像      │    │          │    │ 矩阵      │    │ 分解     │      │
│  └──────────┘    └──────────┘    └──────────┘    └─────┬────┘      │
│                                                       │            │
│                                                       ▼            │
│                                               ┌──────────────┐    │
│                                               │ 选择前 k 个   │    │
│                                               │ 特征向量（特征脸）│   │
│                                               └──────┬───────┘    │
│                                                       │            │
│  每张人脸 → 投影到特征脸空间 → 得到 k 维特征表示 → 存储          │
│                                                                     │
│  识别阶段：                                                          │
│  新人脸 → 同样的投影 → 得到 k 维特征 → 与存储特征比距离 → 判定身份    │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 5.3 关键细节

1. **计算技巧**：当人脸维度 $d$ 远大于样本数 $M$ 时（如 $d = 11368, M = 100$），直接计算 $d \times d$ 的协方差矩阵计算量太大。可以转而计算 $M \times M$ 的矩阵 $L = A^T A$（其中 $A$ 是归一化后的数据矩阵），再利用关系 $A A^T v_i = \lambda_i v_i \iff A^T A (A^T v_i) = \lambda_i (A^T v_i)$ 求解。

2. **特征脸（Eigenface）**：将特征向量还原为图像，可以直观地看到 PCA 提取的"人脸主要特征"——它们看起来像模糊的人脸轮廓，捕捉了光照、表情、姿态等主要变化方向。

3. **维度选择**：原始论文表明，仅需前 **7 个**主成分即可实现较高的识别准确率，远低于原始的 11368 维。

## 6. 高斯混合模型（GMM）与 EM 算法

### 6.1 从硬聚类到软聚类

| | K-means | GMM |
|--|---------|-----|
| **划分方式** | 硬划分：每个点 100% 属于某个簇 | 软划分：每个点以一定概率属于每个簇 |
| **簇的形状** | 球形（由距离度量决定） | 椭球形（由协方差矩阵决定） |
| **概率输出** | 无 | 可以输出属于各簇的概率 |
| **生成能力** | 不能生成新数据 | 可以从学习到的分布中采样生成新数据 |

### 6.2 高斯分布（正态分布）回顾

一维高斯分布由两个参数完全确定：

$$
\mathcal{N}(x \mid \mu, \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)
$$

| 参数 | 含义 | 维度 |
|------|------|------|
| $\mu$（均值） | 分布的中心位置 | $d$ 维向量 |
| $\Sigma$（协方差矩阵） | 分布的形状和展布方向 | $d \times d$ 矩阵 |

### 6.3 GMM 的模型定义

假设数据由 $K$ 个高斯分布**混合生成**，每个样本的生成过程为：

1. **掷一个有 $K$ 面的骰子**，以概率 $\pi_k$ 选出第 $k$ 个高斯分布（$\pi_k$ 称为**混合系数**，满足 $\sum_k \pi_k = 1$）。
2. 从选中的第 $k$ 个高斯分布 $\mathcal{N}(\mu_k, \Sigma_k)$ 中采样一个数据点。

GMM 的概率密度函数为：

$$
p(x) = \sum_{k=1}^{K} \pi_k \cdot \mathcal{N}(x \mid \mu_k, \Sigma_k)
$$

### 6.4 模型参数

| 参数 | 符号 | 含义 |
|------|------|------|
| 混合系数 | $\pi_k$ | 第 $k$ 个高斯成分的权重（"骰子"的概率） |
| 均值向量 | $\mu_k$ | 第 $k$ 个高斯成分的中心位置 |
| 协方差矩阵 | $\Sigma_k$ | 第 $k$ 个高斯成分的形状和展布 |

### 6.5 EM 算法（Expectation-Maximization）

GMM 的参数估计同样使用**交替优化**的思想，具体实现为 **EM 算法**：

```
┌─────────────────────────────────────────────────────────────────────┐
│                     EM 算法流程（GMM）                               │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  输入：数据集 {x₁, ..., xₙ}, 簇数 K                                 │
│                                                                     │
│  初始化：随机设定 πₖ, μₖ, Σₖ                                       │
│                                                                     │
│  ┌─────────────────────────────────────────────────────────────┐    │
│  │  循环直到收敛：                                               │    │
│  │                                                              │    │
│  │  E 步（Expectation）：估算每个数据点属于各簇的概率              │    │
│  │                                                              │    │
│  │    γ(zₙₖ) = P(zₙ=k | xₙ)                                   │    │
│  │          = [πₖ · N(xₙ | μₖ, Σₖ)] / [Σⱼ πⱼ · N(xₙ | μⱼ, Σⱼ)] │    │
│  │                                                              │    │
│  │    含义：在当前参数下，样本 xₙ 来自第 k 个高斯的概率           │    │
│  │    分子：第 k 个高斯产生的可能性 × 该成分的权重                │    │
│  │    分母：归一化（保证所有簇的概率之和为 1）                    │    │
│  │                                                              │    │
│  │  M 步（Maximization）：更新模型参数                            │    │
│  │                                                              │    │
│  │    Nₖ = Σₙ γ(zₙₖ)              ← 第 k 个簇的"有效样本数"      │    │
│  │    μₖ = (1/Nₖ) Σₙ γ(zₙₖ) xₙ   ← 更新均值                   │    │
│  │    Σₖ = (1/Nₖ) Σₙ γ(zₙₖ)(xₙ-μₖ)(xₙ-μₖ)ᵀ  ← 更新协方差    │    │
│  │    πₖ = Nₖ / N                  ← 更新混合系数                │    │
│  └─────────────────────────────────────────────────────────────┘    │
│                                                                     │
│  输出：学到的参数 {πₖ, μₖ, Σₖ}                                      │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 6.6 GMM vs K-means 的关系

```
┌─────────────────────────────────────────────────────────────────────┐
│                 GMM 与 K-means 的内在联系                            │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  K-means：                                                          │
│    分配 → 硬标签（0 或 1） → 更新簇中心                               │
│                                                                     │
│  GMM（EM 算法）：                                                    │
│    E 步 → 软标签（概率 γ ∈ [0,1]） → M 步更新参数                     │
│                                                                     │
│  当所有高斯成分的协方差 Σₖ → σ²I（σ → 0）时：                         │
│    GMM 退化为 K-means                                                │
│    （软标签变为硬标签，概率分配变为 0/1 分配）                         │
│                                                                     │
│  ┌──────────┐          ┌──────────┐                                 │
│  │ K-means  │ ← 特例 ← │   GMM    │                                 │
│  │ (硬划分)  │          │ (软划分)  │                                 │
│  └──────────┘          └──────────┘                                 │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 6.7 GMM 的优势

- **软划分**：提供概率归属，更灵活。
- **椭球形簇**：通过协方差矩阵适应不同形状。
- **生成能力**：学习到分布参数后，可以采样生成新数据（draw from distribution）。
- **更鲁棒**：对数据分布的假设更灵活。

## 7. 前置知识：最大似然估计（MLE）

在深入理解 CNN 的 Loss 之前，我们必须先理解**最大似然估计（Maximum Likelihood Estimation, MLE）**。因为交叉熵损失的本质，就是 MLE 在分类任务中的具体实现形式。

### 7.1 什么是"似然"（Likelihood）？

**似然（Likelihood）**与**概率（Probability）**虽然数学表达式相同，但语义截然不同：

| | 概率（Probability） | 似然（Likelihood） |
|--|---------------------|---------------------|
| **固定什么？** | 固定模型参数 $\theta$，观察数据 $x$ 的变化 | 固定已观测数据 $x$，观察参数 $\theta$ 的变化 |
| **含义** | 在给定模型下，数据出现的可能性有多大？ | 在给定数据下，哪组参数最可能产生了这些数据？ |
| **表达式** | $P(x \mid \theta)$ | $L(\theta) = P(x \mid \theta)$ |

用一个直觉例子来理解：假设你有一枚硬币，抛了 10 次得到 7 次正面、3 次反面。

- **概率问题**：如果这枚硬币是公平的（$\theta = 0.5$），观察到"7正3反"的概率是多少？ → 这是概率。
- **似然问题**：观察到"7正3反"这个结果后，这枚硬币出现正面的概率 $\theta$ 最可能是多少？ → 这是似然。

### 7.2 似然函数的构造

假设我们有 $N$ 个**独立同分布（i.i.d.）**的观测样本，模型的参数为 $\theta$。由于样本之间相互独立，**联合概率**等于各个样本概率的乘积：

$$
L(\theta) = \prod_{k=1}^{N} P(y^{(k)} \mid x^{(k)}; \theta)
$$

### 7.3 从"最大化似然"到"最小化负对数似然"

MLE 的目标是找到最优参数 $\theta^*$，使得似然函数最大化。但直接优化连乘形式存在两个问题：

1. **下溢出（Underflow）**：几百项 $[0, 1]$ 的数连乘会迅速趋近于 0。
2. **求导困难**：连乘的导数需要乘积法则，展开后极为复杂。

**解决方案：取对数**。$\log(\cdot)$ 是严格单调递增的，取对数后连乘变连加：

$$
\log L(\theta) = \sum_{k=1}^{N} \log P(y^{(k)} \mid x^{(k)}; \theta)
$$

再取负号，将"最大化"转为"最小化"：

$$
\theta^* = \arg\min_{\theta} \left[ -\sum_{k=1}^{N} \log P(y^{(k)} \mid x^{(k)}; \theta) \right]
$$

这个表达式就是**负对数似然（NLL）**。**在分类任务中，NLL 的形式与交叉熵损失完全一致。**

```
MLE 的完整推导链：

  观测数据 → 构造似然函数 L(θ) → 取对数（避免下溢出 + 简化求导）
                                         ↓
                                 最大化对数似然
                                         ↓
                                 取负号 → 最小化 NLL
                                         ↓
                                 NLL = 交叉熵（在分类任务中）
                                         ↓
                          ⭐ 这就是 CNN 训练中优化 Loss 的本质
```

> **学习要点**：交叉熵不是凭空选择的公式——它是从"让模型最可能产生观测数据"这个朴素思想出发，经过严格数学推导得出的必然结论。GMM 的 EM 算法本质上也是在做 MLE。

## 8. CNN 计算 Loss 的标准数据流

在实际的 CNN 架构中，一张图片输入网络后，计算 Loss 经历以下严格步骤：

### 8.1 特征提取与全连接映射（Logits）

输入图像经过多层卷积、池化、激活后被展平，最终通过全连接层，输出**无界的实数向量**——**Logits**（$z \in \mathbb{R}^C$）。

> **为什么叫 Logits？**
> Logit 来源于统计学，定义为概率的对数几率：$\text{logit}(p) = \log \frac{p}{1-p}$。在深度学习中，Logits 被泛化为分类器最后一层的原始输出，可以取任意实数值。

### 8.2 概率归一化（Activation）

#### Softmax 函数（多分类）

$$
\hat{y}_i = \frac{e^{z_i}}{\sum_{j=1}^{C} e^{z_j}}
$$

**性质**：非负性（$\hat{y}_i > 0$）、归一性（$\sum \hat{y}_i = 1$）、单调性（$z_i$ 越大 $\hat{y}_i$ 越大）、指数放大的"赢家通吃"效应。

#### Sigmoid 函数（二分类）

$$
\hat{y} = \sigma(z) = \frac{1}{1 + e^{-z}}
$$

**与 Softmax 的关系**：二分类 Softmax 退化为 Sigmoid。

### 8.3 计算批次损失（Batch Loss）

$$
J = \frac{1}{N} \sum_{k=1}^{N} L^{(k)}
$$

**取平均的原因**：使学习率与 Batch Size 解耦；平均操作本质上是蒙特卡洛估计，Batch Size 越大方差越小。

### 8.4 完整数据流

```
┌──────────┐    ┌──────────────┐    ┌────────────┐    ┌──────────┐
│ 输入图像  │───→│ Conv+Pool+FC │───→│   Logits   │───→│  Softmax  │
│ x ∈ R^HWC│    │  (特征提取)   │    │ z ∈ R^C   │    │ (概率归一化)│
└──────────┘    └──────────────┘    └────────────┘    └─────┬────┘
                                                             │
┌──────────┐                                                   ▼
│ 真实标签  │                                            ┌──────────┐
│ y (One-hot) ───────────────────────────────────────→   │CrossEntropy│
└──────────┘                                            └─────┬────┘
                                                             │
                                                             ▼
                                                     ┌──────────────┐
                                                     │   Loss L     │───→ loss.backward()
                                                     │   (标量)      │     (反向传播)
                                                     └──────────────┘
```

## 9. 核心损失函数的数学表达与计算

### 9.1 二元交叉熵（BCE）

$$
L_{\text{BCE}} = - \left( y \log(\hat{y}) + (1 - y) \log(1 - \hat{y}) \right)
$$

| $y$ | Loss | 含义 |
|-----|------|------|
| $y = 1$ | $-\log(\hat{y})$ | $\hat{y} \to 1$ 时 $L \to 0$（正确）；$\hat{y} \to 0$ 时 $L \to +\infty$（强惩罚） |
| $y = 0$ | $-\log(1 - \hat{y})$ | 对称 |

### 9.2 多类别交叉熵（CCE）

$$
L_{\text{CCE}} = - \sum_{i=1}^{C} y_i \log(\hat{y}_i)
$$

由于 One-hot 编码，退化为 $L_{\text{CCE}} = -\log(\hat{y}_c)$（只关注正确类别的预测概率）。

| $\hat{y}_c$ | $-\log(\hat{y}_c)$ | 含义 |
|:--:|:--:|:--|
| 0.99 | 0.01 | 非常自信且正确 |
| 0.50 | 0.693 | 和随机猜测差不多 |
| 0.01 | 4.605 | 极度自信地判错 |

### 9.3 回归损失：MSE

$$
L_{\text{MSE}} = \frac{1}{C} \sum_{i=1}^{C} (y_i - \hat{y}_i)^2
$$

**统计含义**：假设噪声服从高斯分布 $N(0, \sigma^2)$，最小化 MSE 等价于 MLE。

### 9.4 损失函数选择速查表

| 任务类型 | 标签形式 | PyTorch Loss | 理论本质 |
|---------|---------|-------------|---------|
| 多分类（互斥） | 整数标签 | `nn.CrossEntropyLoss` | 多项分布 MLE |
| 多标签分类 | 多热向量 | `nn.BCEWithLogitsLoss` | MLE |
| 二分类 | 标量 `0/1` | `nn.BCEWithLogitsLoss` | MLE |
| 回归 | 连续实数 | `nn.MSELoss` | 高斯分布 MLE |

## 10. 数学本质：为什么使用交叉熵？

### 10.1 视角一：极大似然估计（MLE）

对模型参数做 MLE，取负对数后，在分类任务中恰好等价于最小化交叉熵：

$$
-\sum_{k=1}^{N} \log \hat{y}_{c^{(k)}}^{(k)} = \sum_{k=1}^{N} L_{\text{CCE}}^{(k)}
$$

### 10.2 视角二：KL 散度与信息论

$$
H(P, Q) = H(P) + D_{\text{KL}}(P \| Q)
$$

- $H(P)$ 是真实分布的熵（常数）。
- $D_{\text{KL}}(P \| Q) \geq 0$，当且仅当 $P = Q$ 时取等号。

因此：$\min H(P, Q) \iff \min D_{\text{KL}}(P \| Q)$，即最小化交叉熵等价于最小化模型分布与真实分布的 KL 散度。

```
┌─────────────────────────┐    ┌─────────────────────────┐
│   统计学视角：MLE        │    │  信息论视角：KL 散度      │
│                         │    │                         │
│  最大化 ∏P(y|x;θ)      │    │  最小化 H(P,Q)          │
│         ↓  取负对数     │    │         ↓  H(P)是常数    │
│  最小化 -ΣlogP(y|x;θ)  │    │  等价于 最小化 KL(P||Q)  │
│         ↓              │    │         ↓              │
│  = Cross-Entropy Loss  │    │  = Cross-Entropy Loss  │
└────────────┬────────────┘    └────────────┬────────────┘
             └──────────┬───────────────────┘
                        ▼
             交叉熵损失是理论上最优的选择
```

## 11. 现代深度学习框架中的计算优化

### 11.1 Log-Sum-Exp 技巧

直接计算 Softmax 时，大的 $z_i$ 会导致 $e^{z_i}$ 溢出。通过减去最大值 $m = \max(z)$：

$$
\log(\hat{y}_c) = z_c - m - \log \left( \sum_{j=1}^{C} e^{z_j - m} \right)
$$

由于 $z_j - m \leq 0$，指数项 $\in (0, 1]$，**永远不会溢出**。

### 11.2 梯度的数值稳定性

交叉熵关于 Logits 的梯度极为简洁：

$$
\frac{\partial L}{\partial z_i} = \hat{y}_i - y_i
$$

梯度始终在 $[-1, 1]$ 之间，不会出现梯度消失或爆炸。

### 11.3 PyTorch 中的对应实现

| PyTorch 类 | 包含的操作 | 输入 |
|-----------|-----------|------|
| `nn.CrossEntropyLoss` | LogSoftmax + NLLLoss | 未经激活的 Logits |
| `nn.NLLLoss` | 仅 NLLLoss | 已取 log 的概率 |
| `nn.BCEWithLogitsLoss` | Sigmoid + BCE | 未经激活的 Logits |

> **最佳实践**：永远使用 `CrossEntropyLoss` / `BCEWithLogitsLoss`，不要手动先算 Softmax/Sigmoid。

## 12. 代码实战：LeNet-5 与 SimpleRNN 中的 Loss

### 12.1 LeNet-5 中的交叉熵损失

```python
criterion = nn.CrossEntropyLoss()    # 多分类交叉熵（内置 LogSoftmax + NLLLoss）
optimizer = optim.Adam(model.parameters(), lr=0.001)

outputs = model(inputs)              # shape: (batch_size, 10) — Logits
loss = criterion(outputs, labels)    # 自动完成 Softmax + Log + NLL
loss.backward()                      # 反向传播，梯度 = ŷ - y
```

- `model(inputs)` 输出的是 **Logits**，不是概率。
- `labels` 是整数张量，PyTorch 内部自动视为 One-hot。

### 12.2 SimpleRNN 中的 MSE 损失

```python
criterion = nn.MSELoss()             # 回归任务用 MSE
optimizer = optim.Adam(model.parameters(), lr=0.01)

outputs = model(inputs.float())      # shape: (batch_size, 1) — 预测 sin 值
loss = criterion(outputs, targets.float())  # MSE: mean((ŷ - y)²)
loss.backward()
```

### 12.3 分类 vs 回归：Loss 选择对照

| | LeNet-5（分类） | SimpleRNN（回归） |
|--|----------------|-------------------|
| **任务** | MNIST 10 分类 | 正弦波值预测 |
| **输出** | Logits $\in \mathbb{R}^{10}$ | 标量 $\in \mathbb{R}$ |
| **标签** | 整数 $\{0,...,9\}$ | 连续实数 |
| **损失** | `CrossEntropyLoss` | `MSELoss` |
| **理论** | 多项分布 MLE | 高斯分布 MLE |
| **梯度** | $\hat{y}_i - y_i$ | $2(\hat{y} - y)$ |

## 总结

| 主题 | 核心要点 |
|------|---------|
| **无监督学习** | 无需标签，发现数据内在结构；分为"化繁为简"（聚类/降维）和"无中生有"（生成） |
| **K-means** | 交替优化：分配 → 更新中心 → 重复；简单但需预设 $K$，不适应不规则形状 |
| **DBSCAN** | 基于密度的聚类；自动确定簇数；能识别噪声；关键超参 ε 和 MinPts |
| **PCA** | 对协方差矩阵做特征值分解；最大可分性 = 最近重构性；选择前 $k$ 个主成分降维 |
| **Eigenface** | PCA 在人脸识别中的经典应用；前 7 个主成分即可实现高准确率识别 |
| **GMM** | 概率软聚类；EM 算法（E 步估算归属概率，M 步更新参数）；可以生成新数据 |
| **EM 算法** | 交替优化的概率版本；K-means 是 GMM 在 $\Sigma_k \to 0$ 时的特例 |
| **MLE** | 找到使观测数据出现概率最大的参数；取负对数后转化为最小化 NLL |
| **交叉熵** | 分类任务的 NLL；最小化交叉熵 = 最小化 KL 散度 = 拟合真实分布 |
| **Log-Sum-Exp** | 减去最大值防止指数溢出，保证数值稳定性 |
